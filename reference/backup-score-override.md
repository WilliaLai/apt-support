# 我手填的備用分數什麼時候會被覆寫？

APT 會在兩種時機更新您的分數：①每次您重新連結 DUPR 帳號；②DUPR 通知 APT 您的分數有更新時（自動同步，個人資料頁會顯示「分數最後同步」時間）。若 DUPR 認定您的信心度已達 60%（穩定），APT 改用 DUPR 分數並清除手填備用值；若仍未達，您手填的值保留。
