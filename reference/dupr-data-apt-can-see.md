# 連結後 APT 看得到我的什麼 DUPR 資料？

一定看得到：DUPR ID、目前的雙打／單打分數、分數信心度（達 60% 視為穩定，未達為暫定）。需要您授權才看得到：DUPR Full Name。APT 只會把 DUPR 的 ID、分數與 Full Name 記進您的帳號；您的性別與生日是您自己在 APT 個人資料填寫的，不是從 DUPR 取得。APT 不會讀取您在 DUPR 的比賽紀錄、好友或私訊。
