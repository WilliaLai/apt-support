# 什麼是 DUPR？為什麼 APT 要跟 DUPR 連結？

DUPR (Dynamic Universal Pickleball Rating) 是國際公認的匹克球評分系統。APT 與 DUPR 為合作夥伴，您在 APT 賽事所累積的成績可以同步到您的 DUPR 帳號，計入您在 DUPR 平台上的官方評分；APT 站內的 DUPR 組別也直接以您真實的 DUPR 分數做分組，比賽公平度更高。透過這個合作，您只需要管理一個 DUPR 帳號，就能跨 APT 賽事與 DUPR 全球生態共用一致的評分資料。
