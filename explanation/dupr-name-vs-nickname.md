# 我的 DUPR Name 跟報名名單顯示的名字為什麼不一樣？

APT 全站名單一律以您的「暱稱」優先顯示（即使您已授權 DUPR Full Name）。DUPR Name 主要用於 DUPR CSV 匯出時跟 DUPR 後台對齊比賽紀錄；場主 / 球員實際看到的名單來源是 APT 暱稱。
