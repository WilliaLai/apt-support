# APT 支援中心

APT App 的使用說明，依[Diátaxis](https://diataxis.fr/)的方式分成教學、操作指南、參考資料、觀念說明四類整理；目前收錄 DUPR 帳號連結與 DUPR 成績上傳兩個主題。請依你現在的需要挑一類看。

## 教學（第一次使用，從頭跟著做）

### DUPR 成績上傳

- [第一次上傳 DUPR 成績（團長）](tutorials/dupr-first-upload.md)：從申請俱樂部認證、建立含 DUPR 組別的活動、輸入比分，到結束活動、在上傳區把成績送出，一次走完。

- [我第一次連結沒勾 Full Name，怎麼補授權？](how-to/authorize-dupr-full-name.md)：到 DUPR 後台補勾 Full Name 並回 APT 重新連結。
- [我想斷開 APT 跟 DUPR 的連結，怎麼做？](how-to/disconnect-dupr-account.md)：從 DUPR 後台斷開連結的步驟。

- [處理「需要你確認」的場次](how-to/handle-needs-confirm.md)：逐場決定要不要送到 DUPR。
