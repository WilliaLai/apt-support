# DUPR 一鍵上傳 使用說明

「DUPR 一鍵上傳」讓俱樂部在活動結束後，把 DUPR 組別的比賽成績一次送到 DUPR，不用再一場一場整理。這份說明寫給：

- **團長（俱樂部管理員）**：申請俱樂部的 DUPR 認證、上傳成績的主要負責人。
- **主辦**：被列為活動主辦的人，也可以上傳這場活動的成績。
- **球員**：想知道誰會幫你上傳成績、你自己在 App 上看得到什麼。

說明依照 [Diátaxis](https://diataxis.fr/) 的方式分成四類，請依你現在的需要挑一類看。
