# 怎麼把 DUPR 帳號連結到 APT？

把您的 DUPR 帳號連結到 APT，讓 APT 取得您的 DUPR ID 與分數。

## 步驟

1. 進入「我的」→ 點「查看個人資料 ›」→ 在「編輯資料」頁的「比賽用資料」找到 DUPR 欄位，點藍色「🔗 連結 DUPR 帳號」按鈕（已連結過則顯示「🔄 重新連結 DUPR 帳號」）。
2. 會跳出 DUPR 登入頁，輸入您的 DUPR 帳號密碼。
3. 第一次連結時 DUPR 會問您「同意 APT 看到哪些資料」，建議勾選 Full Name 讓您的活動名單顯示 DUPR 平台姓名（不勾選也可以，APT 會用您的暱稱顯示）。
